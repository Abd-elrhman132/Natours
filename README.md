# Natours Landing Page 🌿

A modern, responsive landing page for a fictional tour company, **Natours**. This project is built using HTML and CSS (with Sass) and showcases elegant design, responsive layouts, and modern CSS techniques.

![Natours Preview](https://abd-elrhman132.github.io/Natours/img/hero-small.jpg)

## 🌟 Features

- Fully responsive layout for mobile, tablet, and desktop
- Reusable CSS utility classes
- Animated text and buttons
- Custom grid system
- Beautiful hero section and tour cards
- Optimized assets and clean file structure

## 🚀 Demo

👉 [Live Website](https://abd-elrhman132.github.io/Natours/)

## 🛠️ Technologies Used

- HTML5
- CSS3
- Sass (SCSS)
- BEM Methodology
- Flexbox & CSS Grid
